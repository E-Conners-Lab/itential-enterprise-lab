# 0019 — Alpine Linux 3.24.1 for tiny endpoints and utility containers

- **Status:** accepted
- **Date:** 2026-09-06

## Context

Branch hosts need a minimal Linux node (0.5 GB RAM) for reachability tests.
Alpine 3.24.1 is current (3.24 supported to 2028-06-01) with published
checksums (manifest 2.10).

## Decision

**Alpine 3.24.1** virt ISO / cloud qcow2 for EVE-NG endpoints (`linux-
alpine-3.24.1`), container tag `alpine:3.24.1` where a base image is needed.

## Consequences

Negligible cost; bump on each Alpine minor with a manifest edit.
