# 0013 — vEOS-lab runs EOS 4.35.6M, replacing the loaded 4.33.1.1F

- **Status:** accepted
- **Date:** 2026-09-06

## Context

EVE-NG holds `veos-4.33.1.1F`, an early feature build of a train that has
since had nine maintenance rebuilds. On 2026-09-06 the newest train in M (fix-
only) phase is 4.35 (4.35.6M, 2026-08-18); 4.36 is F-only. EVE-NG's how-to
lists 4.34.0F as tested. The Containerlab twin must run the same version
(manifest 2.4).

## Decision

**EOS 4.35.6M** for vEOS-lab, `vEOS64-lab-4.35.6M.qcow2` with `Aboot-veos-
serial-8.0.2.iso`, EVE-NG folder `veos-4.35.6M`, 2 vCPU / 4 GB per node,
`zerotouch disable` at first boot.

## Consequences

Seven switches cost 28 GB inside EVE-NG. 4.34.8M is the fallback if 4.35 has
an EVE-NG problem. The 4.33 folder is removed after Phase 4 verification.
