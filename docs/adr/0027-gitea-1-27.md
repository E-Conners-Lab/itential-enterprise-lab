# 0027 — Gitea 1.27.3 via the official chart 12.7.0 with an external CloudNativePG database and an Actions runner on the Containerlab host

- **Status:** accepted
- **Date:** 2026-09-06

## Context

An in-lab git server holds Oxidized output and Itential artefacts and runs the
Containerlab CI job. Gitea 1.27.3 is current; the official chart is 12.7.0
(appVersion 1.27.0, so the image tag is overridden). Bundled database
subcharts are avoided per ADR 0022 (manifest 4.4).

## Decision

**Gitea 1.27.3** (`docker.gitea.com/gitea:1.27.3`) with chart **12.7.0**,
`image.tag` overridden, database on CloudNativePG, Keycloak OIDC login, one
Gitea Actions runner registered from the `clab` VM in Phase 11.

## Consequences

Gitea becomes a dependency of Phases 9 and 11; its backup (dump + CNPG backup)
is part of the nightly off-host copy.
