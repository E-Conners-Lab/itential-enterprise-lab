# 0012 — C8000v runs IOS XE 17.18.4 (Extended Maintenance), replacing the loaded 17.13.01a

- **Status:** accepted
- **Date:** 2026-09-06

## Context

EVE-NG already holds `c8000v-17.13.01a`, a Standard-support release whose
software maintenance ended 2024-11-30. 17.15.x (EM) ends maintenance
2027-03-30 and Cisco's EOL notice points to 17.18.1+. Cisco's recommended EM
releases on 2026-09-04 are 17.18.4 and 17.15.6. 26.1.x has no C8000V feature
delta. gNMI, NETCONF and RESTCONF are documented for 17.18 (manifest 2.3).

## Decision

**IOS XE 17.18.4**, file `c8000v-universalk9_8G_serial.17.18.04.qcow2` (name
pattern to be confirmed at download), EVE-NG folder `c8000v-17.18.04`, 2 vCPU
/ 6 GB per node. Smart Licensing Using Policy needs no registration;
throughput set to 250 Mbps.

## Consequences

Five routers cost 30 GB inside EVE-NG. The old 17.13 folder is deleted after
Phase 4 verifies the new image. 17.15.6 is the documented fallback if 17.18.4
misbehaves under nested KVM.
